# Regla de Commits de Git

- Todos los mensajes de commit de Git DEBEN escribirse obligatoriamente en **español**.
- Los mensajes deben ser claros, descriptivos y comprensibles para que el desarrollador entienda exactamente qué cambios se realizaron.
- Ejemplo: `git commit -m "feat: rediseño del Hero en fondo claro y trazado HD de ruta por calles de Quito"`
