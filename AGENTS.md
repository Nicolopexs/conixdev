# Reglas del Proyecto ConixDev

1. **Mensajes de Commit de Git en Español**:
   - Todos los mensajes de commit en Git deben ser redactados exclusivamente en **español**.
   - Deben ser descriptivos y detallar claramente los cambios realizados (ejemplo: `feat: rediseño claro del Hero y trazado HD de ruta por calles de Quito`).

2. **Diseño Visual**:
   - Fondo claro (blanco/celeste ejecutivo).
   - Tipografía grande y de alta legibilidad (`Plus Jakarta Sans`).
   - Textos breves e directos.

3. **Muestras Médicas Éticas**:
   - Usar siempre nombres genéricos de demostración (`MEDICAMENTO DEMO A`, `FÁRMACO GENÉRICO B`), evitando marcas comerciales reales por confidencialidad.

4. **Sin Menciones de Facturación SRI Directa**:
   - No promocionar servicios de integración directa con Web Services del SRI, comprobantes XML ni firma p12. Enfocarse en integraciones de APIs generales, ERPs, CRMs y pasarelas de pago.

5. **Sin Títulos ni Términos Indebidos (Sin 'Ingeniero' ni 'Proceso de Ingeniería')**:
   - No atribuirse el título de 'ingeniero' ni usar frases como 'Proceso de Ingeniería' o 'equipo de ingeniería'.
   - Usar terminología auténtica y transparente: 'Proceso de Desarrollo', 'Desarrollador de Software', 'Metodología de Trabajo' o 'Especialista en Software'.
